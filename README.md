## 全画面3Dの「意味不明な旅」・迷子と風洞（最新版）

トップURLは `/3d/` へ案内。Three.jsの3Dキャンバスを**画面全体に固定**し、スクロール距離でカメラ・とびとくんの歩行/飛行ポーズ・照明・背景色・場所を連続的に変える構成。既存ページのように3Dを四角いHeroの中へ閉じ込めない。

- **基地→滑走路→格納庫→琵琶湖：** オリジナルの立体とびとくん、模型的な滑走路、工房、40mの翼を模した格納庫、大空と湖面。正確なS-320のGLBモデルは従来どおり点検ビューアでユーザー操作後に読み込む。
- **ゲームを残す：** 元のフライトゲーム、やきとり脱出、元の風洞シミュレーターは `legacy.html` に残し、新3Dサイトからリンク。新しい追い風キャッチも維持。
- **とびとくんを探せ：** カラフルな架空の格納庫に200個以上の物体を配置した、6つの隠しものを探すゲーム。タップ、キーボード、ズーム、ヒント、結果共有に対応。既存著作物の画像は使用しない。
- **なんでも風洞：** ラーメン、冷蔵庫、CPUクーラー、納豆、猫、地球など、あり得ないものを入れる意図的にふざけた実験。**科学シミュレーターではない。**
- **サイト暴走モード：** 警告テロップ、紙吹雪、グリッチ、重力異常、勝手に降ってくる小物。演出停止可能。
- **音：** ユーザーが明示的にONにしたときだけ足音・弱い風音をWeb Audioで生成。自動再生しない。
- **安全弁：** WebGL不可/低メモリ端末/動きを減らす設定で2D表示。画面内の動作停止・音声停止・異常演出停止を個別に実装。

主要ファイル：`3d/world.js`、`3d/cinematic.css`、`3d/chaos.js`、`3d/chaos.css`、`3d/journey.js`。テスト：`tests/tobito-cinematic.test.cjs`。テーマは「無駄に壮大・無駄にくだらない」。SNSでの拡散はサイト単体では保証できない。

ページのルート：`/` → `/3d/`。従来のゲーム全部入り版：`/legacy.html`。WordPress向け `index.php` と `page-tobito.php` は元のゲームを維持。

## 映像的な3D空間への移行（2026-11-10）

以前の3Dページは『2人旅』と書きつつLPのカードを順番に読む構造で、固定の吹き出しが相棒をチャットウィジェットにしていた。これを改善する。

- `3d/world.js` は **1つの継続するWebGL空間** を描画する。格納庫・滑走路・S-320をモチーフにした巨大翼・湖面を順に配置し、ページのスクロール量をカメラの実際の前進量と視線移動に変換。とびと君は同じ空間内で歩き、停止・振り返り・飛翔する。
- `3d/cinematic.css` は画面いっぱいのシーンを主体にし、LP的な背景・ボックスを減らす。固定のチャット吹き出しと重複した3D操作ボタンは非表示。必要な画面UIは音声の明示操作・モーション停止・現在地に集約する。
- あえて説明的な『旅です』『あなたが主人公』を減らし、シャッター、足音、工具、風向きなどの環境描写に変更。
- 音は既定OFFで、利用者が押した場合のみブラウザ内で生成。`prefers-reduced-motion`・低メモリ・WebGL失敗時は2Dの原画を残す。
- `3d/chaos.js` / `chaos.css` は本家の「とびとくんを探せ」6対象のオリジナルSVG格納庫探索と、ラーメン・冷蔵庫・CPUクーラーなど8種類を入れる架空の風洞を実装。既存の真面目な風洞・フライト・やきとりゲームへの導線を維持。
- 実機ブラウザ表示・性能・視覚的な最終判断は別途確認が必要。手描き3Dキャラクターは既存の2D素材を参考にした**試作品**で、監修済みモデルではない。巨大翼は舞台装置であり実機を忠実に再現したものではない。

## 開発・更新手順

`index.php` と `assets/` を編集し、プロジェクト直下で次を実行します。

```sh
bash scripts/build.sh
```

スクロール動作・ページ生成のテスト、WordPress版の生成、PHP構文チェック、静的HTMLの生成、`wordpress-theme-files/` の同期を順に実行します。Node.js・Python 3・PHPが必要です。ローカルプレビューは `php -S 127.0.0.1:8088` で起動します。

- `assets/js/prologue-scroll.js` の `SCENES`：各場面の登場・退場位置とプレビュー位置。
- `index.php` の `TOBITO:CONTENT:START/END`：通常版とWordPress版で共有する本文の範囲。
- `scripts/templates/`：WordPress版の前後に付けるPHPテンプレート。

`index.html` は3Dサイトへの入口を含むGit管理ファイルです（ローカルビルドでは上書きしません）。`legacy.html` はGitHub Actionsが `index.php` から生成してブランチに同期する旧サイトの静的版、`preview.html` はローカルビルドで生成するプレビューです。WordPress用 `page-tobito.php` / `wordpress-theme-files/` は別の生成フローで更新します。

## 🌟 主な機能と特徴

1. **🌌 フルスクリーン・スクロールテリング (Scrollytelling Engine)**:
   - 明電舎スタイルに着想を得た、フルスクリーンピン留め＆シームレス連動LP。
   - **Lenis スムーススクロール**: 慣性のある極上のシルキースクロール操作感。
   - **背景カラーシフト**: 夜明けのインディゴ（#0A1128）→ 早朝の琵琶湖・朝焼け（#FED7AA / #BAE6FD）→ 大空への飛翔（#0284C7 / #FFFFFF）へ滑らかにブレンド。
   - **気流SVGストリームライン**: スクロール連動で風が画面を吹き抜けるダッシュオフセット演出。
   - **超巨大動詞タイポグラフィ**: 「飛べない鳥よ、」「ペダルを踏め。」「風を掴め。」「空を翔べ。」
   - **Chapter 1（誕生と意志）**: 暗闇のシルエットから光を浴びて実体化するピン留めストーリー。
   - **Chapter 2（工学の美 Bento）**: 外側から吸い付くように収束するミニマル・スペックBento。
   - **Chapter 3（3D Fly-through Archive）**: Z軸奥行きを舞い上がるステッカーアーカイブ。
2. **⚡「村田製作所 デンシランド風」フィジカル・マイクロインタラクション**:
   - **スプリング物理 (Spring Physics)**: 線形変化を排し、弾力のある物理演算（`stiffness: 350, damping: 25`）でホバー（`scale: 1.04, y: -8px`）＆タップ沈み込み（`scale: 0.94` → ボヨンと復元）。
   - **3D Parallax Tilt**: マウス座標に追従してカードが多層空間で立体的に傾く立体視差（Layered Depth）。
   - **マグネティック・ボタン (Magnetic Button)**: カーソルが近づくと引力で吸い寄せられる心地よい磁力インタラクション。
   - **FLIP カードモーフィング展開**: ステッカーをクリックした際、触ったカードそのものが画面中央へ有機的に滑らかに拡大展開するモーフィングモーダル。
3. **🎛️『TBT Hangar & Flight Console（機体格納庫 & 計器コンソール）』 (Inspired by yami.net)**:
   - **コクピット・テレメトリHUD**: ケイデンス（CADENCE RPM）と琵琶湖の風速（WIND SPEED m/s）スライダーを操作可能。対気速度やパイロット合計出力をリアルタイム算出。風速を上げすぎると、とびとくんが「強風注意トビ〜〜！！💦」とバタバタ焦るリアクションアニメーションが発火！
   - **ドラッグ＆ドロップ 物理ステッカーデスク**: ステッカーを掴んで机の上を自由にドラッグ可能。掴むと浮き上がり、放すと慣性でコトンと落ちる（「散らす」「整列」ツールバー付き）。
   - **Web Audio API 音響合成 (Sound FX)**: 外部ファイル依存なしにブラウザ内部で波形合成。ステッカー剥がし音（ペリッ）、スイッチ音（カチッ）、ビープ音（ピロッ）、とびとくんリアクション音（ピヨッ！？）を再生（ミュート切替対応）。
   - **隠しコマンド・ターミナル (Easter Egg)**: キーボードで「`TBT`」と打つか、HUDの「CLI」ボタンを押すと、レトロな黒いCLIターミナルが出現！部室の守り神・傘立て（フェアリング講習会）の極秘ログや黒歴史がアンロック。
4. **🕊️ Meowsing風フライトコンパニオン（画面常駐演出）**:

   - マウスカーソル追従・旋回ホバリング・飛行機雲パーティクル。

## ⚡ 秘密のサーバー計算API（Flight Dynamics REST API）

外部ツール（Python、curl、各種スクリプト）から、サーバーサイドで高精度な航空力学シミュレーション（DAE-21翼型モデル、地面効果、連打推力、失速・過大G破断判定）を実行できる非公開REST APIです。

### 1. APIキーの確認・再生成（CLI）
秘密APIキーは非公開設定ファイル（`config.secret.php` / `.env`）に自動生成・保存され、外部から保護されています。

```bash
# 現在のAPIキーを確認
php scripts/generate_api_key.php

# APIキーを新しくローテーション（再生成）
php scripts/generate_api_key.php --rotate
```

### 2. 計算APIの呼び出し（curl）
```bash
curl -X POST http://127.0.0.1:8088/api/flight-calc.php \
  -H "Content-Type: application/json" \
  -H "X-API-KEY: YOUR_SECRET_API_KEY" \
  -d '{
    "pilot_power": 450,
    "cadence_rpm": 85,
    "target_pitch_deg": 1.2,
    "wind_speed": 2.0,
    "sim_duration_sec": 120,
    "include_trajectory": true
  }'
```

### 3. Pythonクライアントからの実行
```bash
python3 scripts/test_calc_client.py
```

## とびと君の独立GLBモデル v3（2026-11-11）

従来は `3d/tobito-character.js` のプロシージャルな球・押し出し図形のみで表示していた。現在は **`3d/models/tobito-v3.glb` がメインの3Dモデルデータ**。GLBにはメッシュ、PBRマテリアル、Body/Face/Comb/Wing/Leg/Eye の可動階層を含む。

- **表示統合**：`3d/world.js` は訪問者が3D区間に近づいたときだけ GLTFLoader でモデルをロード。GLBのノードを既存の歩行・羽ばたき・視線・まばたきに接続。ロードできない端末は `3d/tobito-character.js` の既存モデルへフォールバック。
- **見た目の確認**：`3d/model-review.html` にGLB専用の360度レビュー画面を設置。ドラッグ・キーボード・自動回転・ズーム、原画イラストとの比較ができる。新サイトのプロフィール欄からリンク。
