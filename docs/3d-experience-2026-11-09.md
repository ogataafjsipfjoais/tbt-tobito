# とびとくんの部屋：3D化 第1段階（2026-11-09）

## 目的
公式マスコットを中心にした3D体験型サイトへ、既存ページの機能・文章・構造を破壊せず移行する。

## 実装済み
- プロローグの公式2D画像に重ねる、Three.jsで描画した立体とびとくん
- 色・シルエットのモチーフ：四角い白い頭、赤いトサカ、黄色いくちばし、眠そうな目、青いつなぎ、黒い靴
- ドラッグ回転、90度回転ボタン、羽ばたきボタン、正面復帰
- スクロール演出・既存プロフィール・機体3Dゲーム・アーカイブを維持
- WebGL無効、低メモリ端末、動きを抑える設定、コンテキストロスト時には従来の2D画像を表示
- IntersectionObserverとページ可視状態による描画休止、DPR制限
- WordPressテンプレートとPHP版の両方を更新
- 静的プレビュー生成とGitHub Pages配信のためのワークフローを配置

## モデルの扱い
現時点の立体モデルは、リポジトリにあるマスコットのイラストを参考にコードで構築した**試作3D表現**。公式の監修済み3D原型や3Dスキャンではない。実物への忠実度を上げる場合は提供された正式な立体原型に差し替える。

## デザインの判断
別ページへ遷移させる方式より、既存のスクロール物語に3Dキャラクターを統合する方式を優先した。新たな大型ライブラリは導入せず、既存のThree.jsを再利用する。既存機能は削らない。

## テスト・運用
- 更新したJSの構文とHTMLの接続関係は静的チェックで確認
- tests/tobito-3d.test.cjs を既存テストに追加
- scripts/build.sh のJS構文チェック対象に追加
- PC、スマートフォン、タブレット、実機WebGL、外部CDN読み込みについてはブラウザでの目視・操作検証が必要
- WordPress本番サーバーへのアップロードは別作業
- GitHub Pagesは**静的プレビュー**。PHPの投稿保存やサーバーAPIはGitHub Pagesでは動かない。Pages有効化とActions実行の成功確認が必要
